# صيدلية الطيب - منصة عروض اليوم الوطني السعودي 96 🇸🇦
### Altayeb Pharmacy - National Day 96 Offers Single Page Application (SPA)

منصة متكاملة بنظام **Hub and Spoke** مبنية باستخدام **React (Vite) + Tailwind CSS** لإدارة وتقديم عروض اليوم الوطني السعودي 96 لصيدلية الطيب.

---

## 🌟 الميزات الرئيسية (Features)

### 1. المتجر وواجهة العملاء (Client Store):
- **طابع وهوية اليوم الوطني 96:** ألوان الأخضر السعودي الملكي (`#006C35`) والذهبي والأبيض، باتجاه RTL وخطوط عربية أصيلة (Cairo و Tajawal).
- **عداد تنازلي ذكي (Smart Countdown):** مضبوط بدقة لينتهي في **30 سبتمبر الساعة 12:00 منتصف الليل**.
- **نموذج Hub & Spoke للأقسام والماركات:** بطاقات ديناميكية لجميع الماركات والتصنيفات (بيوديرما، كيو في، العناية بالشعر، وأي قسم يتم إضافته).
- **آليات عروض وطنية مرنة:**
  - 🇸🇦 الحبة الثانية بخصم 96%.
  - 🇸🇦 الحبتين بـ 96 ريال فقط.
  - 🎁 1 + 1 مجاناً.
  - 🇸🇦 سعر موحد 96 ريال للحبة.
  - 🏷️ خصم مئوي مباشر (10% - 80%).
- **مودال طلب فوري وسريع:** إدخال (الاسم، الجوال، العنوان) وحساب التوفير تلقائياً مع احتفال فوري وتأكيد الطلب برقم مرجعي (`SA96-XXXXXX`).

### 2. لوحة تحكم الإدارة (Admin Dashboard):
- مسار محمي (`/admin`) لتسجيل دخول الإدارة (الافتراضي: `admin` / `admin`).
- **إدارة الأقسام (Categories):** إضافة وحذف الأقسام وتظهر فوراً في النافبار العلوي وفي المتجر.
- **إدارة المنتجات (Products):** إضافة منتجات جديدة واختيار آلية العرض المخصصة وتحديد الأسعار والصور.
- **إدارة الطلبات (Orders):** متابعة طلبات العملاء مع زر اتصال ومحادثة واتساب مباشرة وتحديث حالة الطلب (جديد / قيد التجهيز / تم التوصيل).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Frontend Framework:** React 19 + Vite
- **Styling:** Tailwind CSS + PostCSS
- **Routing:** React Router v7
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti

---

## 🚀 التشغيل المحلي (Getting Started)

1. تثبيت الاعتماديات:
```bash
npm install
```

2. تشغيل السيرفر المحلي:
```bash
npm run dev
```

3. بناء نسخة الإنتاج:
```bash
npm run build
```

## 🌐 النشر (Production Deployment)
المشروع جاهز ومجهز بملفات التوجيه (`vercel.json`, `_redirects`, `.htaccess`) للرفع المباشر على **Vercel** أو **Netlify** أو **cPanel**.
